## 📌 Project Overview

The **Student Performance Analysis Dashboard** is a data visualization project developed using Microsoft Power BI. It presents student academic performance through interactive visualizations, KPI cards, and filters.

The dashboard helps users explore subject-wise scores and overall student results in a clear and organized format.

## 🎯 Project Objectives

- Analyze student performance across subjects.
- Compare average scores in Mathematics, Reading, and Writing.
- Understand the distribution of overall student results.
- Explore student performance using interactive filters.
- Present academic data through clear and meaningful visualizations.

---

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** — dashboard development and visualization
- **Power Query** — data preparation and transformation, if used
- **DAX** — calculations and measures, if used
- **Student Performance Dataset** — source data for the analysis

---

## 📈 Dashboard Features

### 📊 Key Performance Indicators (KPIs)

The dashboard includes four KPI cards:

- **Average Math Score:** 66.09
- **Average Reading Score:** 69.17
- **Average Writing Score:** 68.05
- **Overall Pass Percentage:** 94.9%

### 📉 Visualizations

- **Average Score by Subject:** Compares average scores across Mathematics, Reading, and Writing.
- **Students by Overall Result:** Donut chart showing the distribution of student results.

### 🎛️ Interactive Filters

The dashboard includes slicers for:

- Gender
- Race/Ethnicity
- Lunch
- Test Preparation Course
- Subject

These filters allow users to explore the available data based on selected categories.

## 🔍 Analysis Opportunities

The dashboard can be used to explore:

- Differences based on lunch type.

- Changes in displayed results when applying subject and demographic filters.

Specific findings should be reported only after checking the dashboard results.

## 🚀 How to Run the Project

1. Install **Microsoft Power BI Desktop**.
2. Clone or download this repository.
3. Open `PBI_Task7.pbix` in Power BI Desktop.
4. If prompted, configure data-source access or refresh the data.
5. Explore the dashboard using the charts and slicers.
